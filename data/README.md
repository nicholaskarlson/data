# Synthetic Teaching Data

This directory publishes the 12 CSV files used throughout the book and one JSON dictionary for each dataset.

## Use

1. Download the CSV named by the chapter.
2. Open it in jamovi Desktop from a fresh session.
3. Compare variable names, roles, measurement levels, and missing-value rules with the matching file under `dictionaries/`.
4. Follow the chapter’s numbered workflow and checkpoint.
5. Compare the requested values with the chapter’s native table, `ANALYSIS_MATRIX.md`, and the matching record under `expected-results/`.

The datasets are deterministic and synthetic. They contain no real participant, student, patient, client, or institutional records. See `PROVENANCE.md` and `SHA256SUMS` for origin and integrity details.
