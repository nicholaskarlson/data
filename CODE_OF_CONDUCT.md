# Code of Conduct

This companion repository is for constructive, public, education-focused support.

Participants are expected to:

- Be respectful and specific.
- Keep issues focused on the book, public companion files, and reproducible Jamovi behavior.
- Avoid posting private, identifiable, clinical, institutional, student, client, thesis, or restricted data.
- Avoid asking for homework answers or individualized consulting.

Maintainers may close, edit, or delete issues that violate these boundaries.
