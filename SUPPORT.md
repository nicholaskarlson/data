# Support

Use GitHub Issues for:

- Errata reports.
- Questions about public companion files.
- Reproducible Jamovi output mismatches.
- Broken public links.

Do not use GitHub Issues for:

- Private data analysis.
- Homework-answer requests.
- Clinical, legal, medical, or individualized statistical consulting.
- Uploading identifiable, restricted, or confidential data.

For best results, include the book version or printing, chapter or page, Jamovi version, operating system, file name, expected result, and observed result.
