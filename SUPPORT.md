# Support

Use GitHub Issues for defects that need to be tracked:

- Errata reports.
- Corrections to the open practice-materials PDF or DOCX.
- Narrow questions about a named public companion file that may expose an ambiguity or defect.
- Reproducible Jamovi output mismatches.
- Broken public links.

Use GitHub Discussions for bounded reader conversation:

- How-to questions and conversation about importing and using the public synthetic datasets.
- Questions about dictionaries, verified result records, and published workflows.
- Ideas for synthetic teaching datasets, documentation, and teaching improvements.
- Questions and feedback about the published open practice materials.

Read [COMMUNITY.md](COMMUNITY.md) before posting. Do not use Issues or Discussions for:

- Private data analysis.
- Homework-answer requests.
- Individualized model selection or analysis planning for unpublished research.
- Clinical, legal, medical, or individualized statistical consulting.
- Uploading identifiable, restricted, or confidential data.

For best results, include the book or resource format, version, chapter or unit, page, problem or solution number when relevant, Jamovi version, operating system, public file name, expected result, and observed result.
