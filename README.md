# Psychology Research Methods and Statistics by Design with Jamovi Companion

Public companion repository for:

*Psychology Research Methods and Statistics by Design with Jamovi: From Scientific Questions to APA-Style Results and Reproducible Evidence*

Book publisher: NEKpress.ca

Author: Nicholas Elliott Karlson

Canonical repository:

`https://github.com/nicholaskarlson/nekpress-psychology-methods-statistics-jamovi-companion`

## Current Status

This repository is a public skeleton. No datasets, screenshots, Jamovi files, or release bundles have been published yet.

Future releases may include:

- Synthetic CSV datasets.
- Data dictionaries.
- Jamovi workflow exports.
- Selected screenshots.
- Student-facing worksheets.
- Errata.
- Versioned release bundles and checksums.

## Where Files Will Live

- `data/` will hold public synthetic datasets and data dictionaries after release.
- `screenshots/` will hold selected public screenshots after release.
- `releases/` explains how versioned companion bundles will be attached to GitHub Releases.
- `ERRATA.md` tracks confirmed corrections.

## Support Boundary

Please use GitHub Issues for reproducible book errors, public companion-file questions, and Jamovi output mismatches.

Do not post private data, identifiable data, clinical data, student records, client data, institutional data, thesis data, restricted data, or homework answers.

This repository does not provide clinical, legal, medical, or individualized statistical consulting.

## Canonical Jamovi Baseline

The book uses official Jamovi Desktop as the canonical reader-facing tool. No custom NEKpress Jamovi fork is required for readers.
